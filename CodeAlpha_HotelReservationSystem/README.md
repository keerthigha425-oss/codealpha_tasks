# CodeAlpha - Hotel Reservation System

## 📌 Overview
The Hotel Reservation System is a Java console-based application developed as part of the CodeAlpha Java Programming Internship. It enables users to manage hotel room bookings, customer information, room availability, and reservation details through a simple menu-driven interface.

## ✨ Features
- View available rooms
- Book hotel rooms
- Cancel reservations
- Customer information management
- Room availability tracking
- Reservation management
- Menu-driven console interface

## 🛠 Technologies Used
- Java
- Eclipse IDE
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling (if applicable)

## ▶️ How to Run

1. Clone this repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Compile and run `Main.java`.
4. Follow the console menu to manage reservations.
