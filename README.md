# CodeAlpha Java Programming Internship Tasks

This repository contains all the tasks completed as part of the **CodeAlpha Java Programming Internship**.

## Projects

### 📘 1. Student Grade Tracker
A Java console-based application for managing student records, calculating grades, and displaying student performance using Object-Oriented Programming.

### 📈 2. Stock Trading Platform
A Java console-based stock trading simulation that supports viewing stocks, portfolio management, transaction history, and file handling.

### 🏨 3. Hotel Reservation System
A Java console-based application for managing hotel room bookings, customer information, room availability, and reservations.
